BASE PROMPT — OFFLINE DEVELOPMENT COMPILER

Goal: preserve complete current documents/components and build a stable leading
reference with the actual local tokenizer. No model/provider calls, source refresh,
DB connections or inference-service changes occur. These artifacts are quarantined:
activation_eligible=false. The catalogue export API supplies scoped owner-selected
sources; Recipe dispatch, trusted seeding and prefix activation remain separate work.

Run from the BrassClaw repository root. Commands work in Linux/macOS terminals.
Python and transformers/tokenizers are required only for target compilation.

The repository also supplies scripts/prefix/release-reference-inventory.json.
It declares 270 original sources, including archived Sempai/Monty candidates, and conservatively selects
13 references; other material is archived, not silently fed into the model view.
Read scripts/prefix/release-reference-inventory.md for scope and remaining gaps.

3. Compile using a local immutable tokenizer snapshot. Replace this one path:

TOKENIZER_DIR="/path/to/local/immutable/ornith-tokenizer-snapshot"
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
python3 scripts/prefix/base-promt-compiler.py \
  --package "prefix-build/sources/$PACKAGE_ID" \
  --output prefix-build/generations \
  --tokenizer-dir "$TOKENIZER_DIR" \
  --max-model-len 131072 --reserve-tokens 8192

The CLI prints one JSON receipt. Read rendered_probe_tokens, shared_prefix_tokens,
probe_count and the exact token-prefix hash. Model context is a caller-declared
technical input, not an assertion that a server supports that size. The minimum
workspace reserve is 8192 tokens for dynamic input/history/reasoning/output.
Increase it when a workload needs more; an oversized complete reference fails
before publication. No source is silently omitted. The mandatory-guide plus
sample-component regression rendered to 119212 tokens with the cached Ornith
snapshot used in development; changing sources/tokenizer can change that number.

For a source-only build without tokenizer geometry:

python3 scripts/prefix/base-promt-compiler.py \

Artifacts under the returned generation ID:
- context.md: each complete document/component rendered once, with compact source IDs.
- evidence.json: unchanged full excerpts and complete section/range/hash navigation.
- raw/<SHA256>: all originals, including explicitly excluded historical material.
- sources.json: complete pinned inventory with inclusion/exclusion reasons.
- server_chat_template.jinja: existing Ornith/Qwen injection adapter, if measured.
- manifest.json: content/engine/tokenizer identities, exact geometry and honest status.

Current template adapter supports the inspected Ornith/Qwen system opening.
Unknown templates fail; cache architecture/block/recurrent-state facts are never
inferred from the tokenizer. The exported template is server-owned: do not also
prepend the same prefix in the client. This command does not install that template.
No current/active pointer or running provider is changed. Cache reuse and model
answer quality remain unverified until actual production/provider qualification.

Optional reviewed development design: exact whole-unit deduplication

Add --evidence-view literal-reference/v2-deduplicated to the COMPILE command
only. It replaces repeated byte-identical complete sections with explicit source/
range references, preserves every original and emits render_map.json. Different
text is never merged, summarized or clipped. Keep literal-reference/v1 for an
accepted v1 design; switching views is a design change, not a hidden Generate
optimization. Both views remain quarantined pending runtime/design acceptance.
