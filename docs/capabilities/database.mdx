BrassClaw uses **PostgreSQL** as its sole persistence layer. All component
storage, conversation history, Monty VM settings, provider definitions, secrets,
and routine state live in PostgreSQL.

<Warning>
libSQL/SQLite is not a supported production or personal-use backend. The
`libsql` feature flag in the BrassClaw repository gates a one-way migration
importer for upgrading from an old single-user libSQL installation to
PostgreSQL — it is not an active backend choice. If you see references to
`DATABASE_BACKEND=libsql` or `LIBSQL_PATH`, those belong to that
migration-only path.
</Warning>

## Quick start

### Embedded PostgreSQL (default for local single-host installs)

When `BRASSCLAW_PG_URL` is not set, BrassClaw starts an embedded PostgreSQL
instance automatically on first launch. No external database server or
installation steps are needed.

```bash
# Optional: override the embedded Postgres port (default: 5434)
export BRASSCLAW_EMBEDDED_PG_PORT=5434

# Optional: allow LAN access (written to postgresql.conf on first boot only)
export BRASSCLAW_EMBEDDED_PG_LISTEN_ADDRESSES=0.0.0.0
```

The embedded database stores its data under `$BRASSCLAW_REBORN_HOME`
(default: `~/.brassclaw/reborn`).

### External PostgreSQL

For production deployments, multi-host setups, or existing PostgreSQL
infrastructure, point BrassClaw at an external instance:

```bash
export BRASSCLAW_PG_URL="postgres://brassclaw:your-password@localhost/brassclaw"
```

`BRASSCLAW_PG_URL` is required for all non-local runtime profiles. When set,
the embedded PostgreSQL instance is not started.

## Requirements

- PostgreSQL 15 or later
- The `pgvector` extension for embeddings and hybrid search

### Install pgvector

<AccordionGroup>
  <Accordion title="Docker Compose (recommended for development)" icon="container">
    ```bash
    cd brassclaw
    docker compose up -d postgres
    ```
    This starts `pgvector/pgvector:pg16` on `127.0.0.1:5432` with database,
    user, and password all set to `brassclaw`.

    <Warning>
    These credentials are for local development only. Change `POSTGRES_PASSWORD`
    before any non-local deployment.
    </Warning>
  </Accordion>

  <Accordion title="Ubuntu/Debian" icon="terminal">
    ```bash
    sudo apt install postgresql-15 postgresql-15-pgvector
    sudo systemctl enable --now postgresql
    ```
  </Accordion>

  <Accordion title="macOS (Homebrew)" icon="terminal">
    ```bash
    brew install postgresql pgvector
    brew services start postgresql
    ```
  </Accordion>
</AccordionGroup>

## External PostgreSQL setup

```bash
sudo -u postgres psql -c "CREATE DATABASE brassclaw;"
sudo -u postgres psql -c "CREATE USER brassclaw WITH PASSWORD 'your-password';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE brassclaw TO brassclaw;"
sudo -u postgres psql -d brassclaw -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

## TLS / SSL

| Mode | Behavior | Use case |
|------|----------|----------|
| `disable` | Never use TLS | Trusted local loopback only |
| `prefer` | Try TLS, fall back to plaintext | Embedded and simple local setups |
| `require` | Require TLS | Remote production connections |

For remote connections, `require` (or stronger) is recommended. The local
embedded Postgres uses `prefer` by default.

```bash
# Append sslmode to the connection URL:
export BRASSCLAW_PG_URL="postgres://user:pw@host/db?sslmode=require"
```

## Search

BrassClaw uses hybrid search combining full-text search (FTS) and vector
similarity when `pgvector` is installed:

```
Keyword matches (FTS)  +  semantic similarity (pgvector)
         └──── Reciprocal Rank Fusion (RRF) ranking ────┘
```

Without pgvector, only full-text search is available.

## Backup and restore

```bash
# Backup
pg_dump -h localhost -U brassclaw brassclaw > backup.sql

# Restore
psql -d brassclaw -f backup.sql
```

For the embedded PostgreSQL instance, the data directory is under
`$BRASSCLAW_REBORN_HOME`. Stopping BrassClaw before copying the directory is
strongly recommended.

## Migrations

BrassClaw applies Flyway-style versioned migrations at startup
(`V1__initial.sql` through the current version). Migrations run automatically
before the component seeder, integrity checker, and turn workers start.

Never edit an already-applied migration. Add a new numbered migration file for
schema changes.

## Troubleshooting

<AccordionGroup>
  <Accordion title="pgvector not found" icon="x-circle">
    ```bash
    sudo apt install postgresql-15-pgvector
    # or compile from source:
    git clone https://github.com/pgvector/pgvector.git
    cd pgvector && make && sudo make install
    ```
  </Accordion>

  <Accordion title="Connection refused" icon="network">
    ```bash
    # Check PostgreSQL is running
    sudo systemctl status postgresql

    # Verify listen addresses
    sudo -u postgres psql -c "SHOW listen_addresses;"
    ```
  </Accordion>

  <Accordion title="Embedded Postgres port conflict" icon="warning">
    ```bash
    # Change the port BrassClaw's embedded instance binds to:
    export BRASSCLAW_EMBEDDED_PG_PORT=5435
    ```
  </Accordion>
</AccordionGroup>
