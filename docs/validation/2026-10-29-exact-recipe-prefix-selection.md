## Delivered producer and consumer

The retained class-21 document supports strict per-variant
`recipe-model-input-bindings/1` metadata. The [Recipe guide](../../recipe.md#retained-model-input-selection-metadata-exact-k3-2-successor)
owns the field contract. Default preserves existing behavior. Selected identifies
an existing profile; the native owner resolves its originally captured compatible
qualification and exact generation. Missing, foreign, ambiguous or changed
selection fails without a Base or catalogue fallback. This version declares a
profile per variant, not arbitrary direct-generation/composite/per-step overrides.

The compiler checks the whole declaration map, including malformed siblings,
unknown variants/fields/tags, null and invalid names. It pins the chosen declaration
as `recipe-model-input-selection/1` within the existing retained selection.
Legacy documents without the metadata keep their original selection bytes.
Later component revisions cannot replace either original selection.

Catalogue binding creates the model prefix source for the actual program/variant.
The existing preflight chain carries its original typed reference through Hooks,
Host, Loop, MCP and the model source. The model source verifies the complete
canonical reference and original provider/model/profile/qualification before
using content. The final gateway receives the reference from the same original
native custodian. No model prompt argument or global client flag selects it.

Ordinary Sempai interceptor review preserves its own original role contract.
A Free workflow reference is forwarded unchanged to the review preflight owner,
which must independently verify its original route. The actual Free workflow
still has no complete native owner: catalogue activation, binding and execution
reject this declaration before it can silently use a default. `/1` model evidence
remains present-prefix only. Recognized/staged intent is not activated support.

No provider selection, original Auth flow/source-use guard, child provenance,
factory capture order, TaskProviderSelection/2 namespace, grant, Tool/effect ID,
queue or SDK wire protocol was replaced. The unused inspection getter introduced
in the prior contract slice was removed rather than kept as an unnecessary API.
