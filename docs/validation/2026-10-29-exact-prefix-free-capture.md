## Delivered capture boundary

The existing factory derives an opaque `LoopModelCaptureContext` only from the
actual retained inspected root Recipe's explicit Free declaration. Ordinary
matching reuses one pure selector over the existing committed resolution, both
before model/config awaits and during later runtime binding. Missing/ambiguous
artifacts fail; there is no rematch, new router or latest lookup. Internal work
uses its existing captured program. Children retain their parent's family.

All existing capture wrappers forward the original declaration. Native sources
check concrete origin, namespace and repeated-capture agreement. Unsupported
adapters reject a declaration rather than drop it. Normal None capture preserves
its previous binding reads/errors; it never means Free. Explicit Free root
capture skips the Prefix binding query. Model preparation and dispatch remain
separate; metadata grants no model I/O or bypass.

`TaskModelProviderSource.capture(parent, capture)` and the existing
`capture_task_model_selection(parent, capture)` now take the optional opaque
context. Normal independent callers pass None. Inheritance returns the original
parent Arc without fresh role selection or binding refill. The interceptor's
Sempai capture uses that same Arc and declaration. This is capture propagation,
not accepted recursive Free child/review execution.
