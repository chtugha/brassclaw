## Result and actual caller

flow pair and invocation before the first write. Strict dedicated schemas reject
unknown fields and malformed JSON with sanitized errors. Setup returns the actual
original state and first expiry. Raw always proves the supplied input; explicit
`/continue` accepts no token and requires the confirmed original publication.

checks acknowledgements, and uses separate raw/reference actions. Reload and
unknown replies preserve IDs; thread/gate/cancel/unmount fence late responses.
Known terminal states disable raw/reference and clear the password input while
Cancel remains available. Unknown publication keeps the entered value for an
explicit retry. EN/DE explain the reference action and failure states. Raw text
is passed exactly or rejected by the existing ingress validator, never trimmed.

replaced the factory's TurnCoordinator but retained its Auth continuation
dispatcher. Credentials could commit while continuation looked for the run in the
earlier substrate. Runtime now attaches the existing Auth facade to the final
coordinator before ingress, preserving all stores/custody/provider/registry ports.
An independent native completion/reference-replay regression passes; the standalone
factory keeps its correct separate coordinator. No alternate loop/store/VM was added.
