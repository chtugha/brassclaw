Keep BrassClaw up to date for the latest features and security patches.

## Check Current Version

```bash
brassclaw --version
# brassclaw 0.13.0
```

## Update by Installation Method

<Tabs>
  <Tab title="Linux (Shell Script)">
    ```bash
    # Re-run the install script (updates in place)
    curl -fsSL https://install.brassclaw.ai | bash

    # Verify update
    brassclaw --version
    ```
  </Tab>

  <Tab title="Ubuntu/Debian (APT)">
    ```bash
    sudo apt update
    sudo apt upgrade brassclaw
    ```
  </Tab>

  <Tab title="macOS (Homebrew)">
    ```bash
    brew update
    brew upgrade brassclaw
    ```
  </Tab>

  <Tab title="Docker">
    ```bash
    # Pull latest image
    docker pull nearaidev/brassclaw:latest

    # Recreate container
    docker stop brassclaw
    docker rm brassclaw
    docker run -d --name brassclaw ...

    # Or with docker compose
    docker compose pull
    docker compose up -d
    ```
  </Tab>

  <Tab title="From Source">
    ```bash
    cd /path/to/brassclaw
    git pull origin main
    cargo build --release
    sudo cp target/release/brassclaw /usr/local/bin/
    ```
  </Tab>
</Tabs>

## Post-Update Steps

### 1. Review Changelog

Check what changed in the new version:

```bash
# View changelog (if installed from source)
cat /usr/local/share/brassclaw/CHANGELOG.md

# Or online
open https://github.com/nearai/brassclaw/releases
```

### 2. Run Migrations

Database migrations run automatically on startup, but verify:

```bash
brassclaw run
# Look for: "Running migrations..." in logs
```

### 3. Restart Service

If running as a service:

```bash
# systemd (Linux)
sudo systemctl restart brassclaw

# launchd (macOS)
launchctl unload ~/Library/LaunchAgents/ai.brassclaw.service.plist
launchctl load ~/Library/LaunchAgents/ai.brassclaw.service.plist

# Homebrew
brew services restart brassclaw
```

## Downgrading

If you need to rollback:

```bash
# Linux/macOS shell script
# Download specific version
curl -fsSL https://install.brassclaw.ai | bash -s -- --version 0.12.0

# Docker
docker pull nearaidev/brassclaw:v0.12.0
```

<Warning>
Downgrading may require manual database rollback if migrations were applied. Always backup before updating.
</Warning>

## Automatic Updates

### systemd Timer (Linux)

```bash
sudo tee /etc/systemd/system/brassclaw-update.service <<EOF
[Unit]
Description=BrassClaw Update Check

[Service]
Type=oneshot
ExecStart=/bin/bash -c 'curl -fsSL https://install.brassclaw.ai | bash'
EOF

sudo tee /etc/systemd/system/brassclaw-update.timer <<EOF
[Unit]
Description=Run BrassClaw update check daily

[Timer]
OnCalendar=daily
Persistent=true

[Install]
WantedBy=timers.target
EOF

sudo systemctl enable --now brassclaw-update.timer
```

## Troubleshooting Updates

<AccordionGroup>
  <Accordion title="Update fails with permission denied" icon="lock">
    ```bash
    # Fix permissions
    sudo chown -R $USER:$USER ~/.local/bin/brassclaw

    # Or update with sudo
    sudo curl -fsSL https://install.brassclaw.ai | bash
    ```
  </Accordion>

  <Accordion title="Database migration fails" icon="database">
    1. Stop BrassClaw
    2. Backup database
    3. Run with debug logging: `RUST_LOG=debug brassclaw run`
    4. Check specific migration error
  </Accordion>

  <Accordion title="Service won't start after update" icon="x-circle">
    ```bash
    # Check logs
    sudo journalctl -u brassclaw -n 50

    # Verify binary
    which brassclaw
    brassclaw --version

    # Reinstall if corrupted
    curl -fsSL https://install.brassclaw.ai | bash
    ```
  </Accordion>
</AccordionGroup>
