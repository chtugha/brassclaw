The self-contained uninstaller requires Python 3.9+ and works on Linux and macOS.
Run it with `sudo` to include system services, installation-owned accounts and
BrassClaw state belonging to other local users. A user-only run handles the
current user's installation.

```bash
curl -fsSL https://raw.githubusercontent.com/chtugha/brassclaw/main/uninstall.sh | sudo bash
```

The script prints its removal inventory before asking for confirmation.
**Press Enter to permanently wipe all discovered BrassClaw state.** Type `keep`
to uninstall while retaining data and credentials, or `cancel` to stop.

<Warning>
A full wipe permanently deletes conversations, embedded PostgreSQL, settings,
credentials, downloaded extensions, workspace files and other BrassClaw state.
</Warning>

## Inspect or run unattended

```bash
bash uninstall.sh --dry-run
sudo bash uninstall.sh --yes
sudo bash uninstall.sh --keep-data
```

`--dry-run` neither stops services nor deletes files. An unattended full wipe
requires explicit `--yes` (the older `--wipe` spelling remains supported).
Without a terminal or an explicit choice, the script stops without removing data.

## Removal coverage

The inventory includes the main executable, Monty worker, legacy aliases,
backups, service units and overrides, embedded PostgreSQL and its qualified
sockets, configuration, dedicated credential entries, extensions, workspace,
logs, caches, identified release downloads and temporary runtime files.
Configured custom state roots are included after safe path validation.
Dedicated package and Docker resources are included when their owners can be
verified; shared Docker volumes are reported for separate cleanup.

The script preserves unrelated user files, shared system dependencies and shared
OS journal records. It refuses a full wipe when ownership cannot be established,
a configured directory is unsafe, a keychain is inaccessible, or an external
PostgreSQL database requires separate cleanup. Resolve reported resources before
claiming a completely clean reinstall. It never drops a shared database by name
or deletes a PostgreSQL socket solely because it uses a familiar port.

## Reinstall

After a successful full wipe, [install BrassClaw](/install) again. The installer
creates fresh state and credentials. With `--keep-data`, the next installation
can reuse the retained state instead.
