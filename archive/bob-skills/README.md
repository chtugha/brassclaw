# Historical Bob skills

Archived on 2026-10-31 from `.bob/skills/`. These files are historical development
workflow snapshots. They are not supported skills, current architecture guidance,
validation requirements or entry points for any current BrassClaw version.
Do not install, invoke, synchronize or reuse them as current instructions.

All eleven skill bodies were preserved byte-for-byte, including the GitHub
workflow corrections made before archival. Each former `SKILL.md` is named
`SKILL.historical.md` here so that it is not a discoverable skill entry file.

`docs/development-policy.md`, `docs/implementation-status.md` and applicable active
skills/subsystem guides. Do not update these snapshots to track later versions.
